# release/

Hier liegt `catalog.pub`: der **öffentliche** Katalog-Schlüssel, mit dem die Pipeline den signierten Katalog gegenprüft
und den sie nach `daedyx/releases` legt. Die Datei ist öffentlich und gehört in Git. Es ist derselbe öffentliche Schlüssel wie bei Daedyx Desk (ein Katalog für alle Apps; Anleitung: `docs/RELEASE.md`). Der geheime Schlüssel kommt nie hierher.
